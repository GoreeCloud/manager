# GoreeCloud Manager — Features

## Current implemented Development capabilities

GoreeCloud Manager currently includes source-validated foundations for:

- authenticated server-rendered administration;
- process-liveness and database-aware readiness endpoints;
- responsive GoreeCloud administration surfaces;
- local System, Light, and Dark appearance preference;
- read-only NetBird peer/private-network visibility;
- read-only Healthchecks scheduled-job visibility;
- read-only Uptime Kuma availability visibility;
- delegated, sanitized Kopia backup-status artifacts;
- delegated, sanitized Beszel resource-status artifacts;
- read-only GoreeCloud Tasks integration;
- bounded Privacy Shield status presentation;
- bounded Everkeep resilience-status presentation;
- containerized deployment packaging and repository CI;
- supply-chain and release-provenance validation foundations.

## Current platform state

The repository is Development and nonconformant under the current platform contract until its required migrations and runtime acceptance gates are completed. The current interface implementation remains mapped to Glaze UI 1.3.0 while current shared Stable authority is Glaze UI 1.6.0.

## Not established by current source

Current source does not establish production publication, production mutation authority, live Wardveil Security acceptance, live GoreeCloud Identity or Mesh acceptance, GoreeCloud Policy or Observability runtime acceptance, target-environment disaster recovery, release approval, or Stable qualification.

See `CAPABILITIES.md` for current capability detail and `FEATURE-ROADMAP.md` for remaining work.
